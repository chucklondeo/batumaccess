ซอฟต์แวร์

เซิร์ฟเวอร์ภายใน คลาวด์ และการชำระเงินหลายประเทศ

ซอฟต์แวร์รองรับการติดตั้งภายใน คลาวด์ หลายภาษา และวิธีชำระเงินตามประเทศ

การติดตั้งเซิร์ฟเวอร์ภายใน

ติดตั้งซอฟต์แวร์ที่จอดรถบนเซิร์ฟเวอร์ภายในสถานที่ สำหรับผู้ซื้อที่ต้องการทำงานแบบออฟไลน์หรือมีข้อกำหนดด้านการเก็บข้อมูลที่เข้มงวด

การดำเนินงานบนคลาวด์

รันซอฟต์แวร์บนโครงสร้างพื้นฐานคลาวด์ของ Batum เพื่อเปิดใช้งานได้รวดเร็วในหลายสถานที่โดยไม่ต้องดูแลเซิร์ฟเวอร์ภายใน

การเชื่อมต่อการชำระเงินทั่วโลก

เชื่อมต่อเกตเวย์การชำระเงินตามแต่ละประเทศและวิธีการชำระผ่าน QR/บัตร สำหรับที่จอดรถแบบไม่ใช้ตั๋วและไม่มีเจ้าหน้าที่

อินเทอร์เฟซหลายภาษา

หน้าจอสำหรับผู้ปฏิบัติงานและลูกค้าสามารถเปลี่ยนภาษาให้เหมาะกับพนักงานท้องถิ่นและผู้ขับขี่

การเชื่อมต่อ API

อินเทอร์เฟซแบบเปิดให้ผู้รวมระบบเชื่อมต่อซอฟต์แวร์กับระบบอสังหาริมทรัพย์ ERP หรือระบบควบคุมทางเข้าที่มีอยู่

รายงานข้อมูลที่จอดรถ

รายงานอัตราการใช้งาน รายได้ และการใช้ช่องทางช่วยให้ผู้ดำเนินงานติดตามประสิทธิภาพและวางแผนกำลังการรองรับ
