FAQ

Common project questions

Clear answers for buyers comparing parking hardware, access control products and software deployment options.

Can Batum parking software be deployed locally?

Yes. Batum parking software can be planned for local server deployment or cloud platform operation depending on the project network and operator requirements.

Which product categories are available?

The current categories include low-voltage servo barrier gates, servo door operators, safety radar sensors and access control accessories.

Can products include downloadable documents?

Yes. Product cards support datasheet download links, and the content hub can record document names and draft document links.
